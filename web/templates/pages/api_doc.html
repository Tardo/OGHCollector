Reviews the license of a set of modules deployed together plus everything they depend on: the license the combined work must be distributed under, proprietary modules pulled in, and conflicts (e.g. a proprietary module on GPL/AGPL code). Handy in CI — fail the build when a finding has "severity": "error". A heuristic based on manifest licenses, not legal advice.

What changed in a module between two Odoo versions: manifest, direct dependencies, models/fields/methods, views and HTTP routes. null when the module doesn't exist at one of them; analysis_available: false when one side has no stored code analysis. Also browsable from a module page (“Compare”).
